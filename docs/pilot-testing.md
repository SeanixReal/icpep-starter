# Beginner pilot template

This is a blank plan and record template, not a report of completed testing. The proposal targets at least 80% completion among eligible Windows testers with administrator access. Confirm the protocol and eligibility with the club before collecting data.

## Run a session

1. Give the volunteer the toolkit URL and explain that the instructions are being tested, not the student's ability.
2. Confirm permission to install software and collect only the minimum needed setup information.
3. Let the volunteer follow the site independently. Record the exact point where they stop or need help; do not quietly guide them and then mark the run independent.
4. Observe navigation, readiness, installation, and the verification runs.
5. Collect concise feedback, fix unclear steps, and retest affected sections.

## Aggregate reporting

Define the C/C++ procedure as successful only when **both** the C and C++ samples compile and produce the expected output. A tester completes both proposed verification procedures only when that C/C++ procedure and the Python run succeed using the website independently.

`Completion rate = eligible independent completions / eligible attempted sessions × 100`

Report the numerator and denominator alongside the percentage. Record exclusions and reasons separately. Do not remove unsuccessful eligible attempts from the denominator. When no eligible sessions have been attempted, report “not yet measured,” not 0% or 100%.

Publish only approved aggregate findings and resulting content changes. Website-local checkmarks are self-reported reminders and must never be used as pilot results.
